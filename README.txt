NAHAMAN MULTI CONCEPT LIMITED — WEBSITE STARTER

Files:
- index.html: website content and page structure
- style.css: visual design and responsive layout
- script.js: mobile navigation and current year

Preview:
Open index.html in a modern web browser. An internet connection is needed for the optional Google Fonts; the page otherwise uses fallback fonts.

Before publishing:
1. Confirm the business name, address, and wording with the business owner.
2. Add an approved business phone/WhatsApp number and email address.
3. Replace general collection descriptions with accurate product categories, availability and pricing.
4. Test all links and the layout on a phone and computer.
5. Choose a domain and hosting provider, then publish the files.
6. Set up Google Search Console after the site is live.

Important:
This is a front-end website. It does not yet include online payments, stock management, customer accounts, or a working enquiry form. The location button opens a Google Maps search for the supplied address; confirm the exact pin before relying on it.
